Prompt. 2 Plaintext

Create a modern, responsive single-page web application for an AI solution company named "Inwit". The overall visual theme should be futuristic, cosmic, and sleek, featuring high-contrast dark space backgrounds, neon cyan/blue highlights, subtle particle effects, and glassmorphism elements.

Key Sections and Requirements:

1. Hero & Interactive Entry Sequence:
   - Initial State: Fullscreen cosmic hero section displaying a glowing geometric 4-point star (SVG outline) in the center. At the bottom or center, place a prominent call-to-action button: "Haz Click para empezar".
   - Interaction / Animation: When the user clicks the CTA button, trigger an explosive starburst animation (Supernova/warp-speed particles transition). As the animation finishes, reveal the main header navigation, a "Log In" button at the top right, and smoothly slide up the main hero container containing the primary query: "¿Quién te ayudará hoy?".
   - Core Services / AI Agents Cards (4 Columns / Responsive Grid):
     Show 4 glassmorphic cards for the initial interactive agents:
     * Seemo: WhatsApp, Mail & Appointment Automation Assistant.
     * Petra: Audiovisual & Graphic Design Agent.
     * Isis: HR & Corporate Interview Specialist Psychologist.
     * Shinko: Manufacturing & Data Analysis Specialist.

2. Scrollable Body & Content Sections:
   - Enable full page scrolling after the initial hero transition.
   - Solutions Interactive Carousel Section:
     Create an interactive visual carousel showcasing what each of the 4 solutions does. Each carousel slide/card should feature a small visual preview panel (demo UI/image layout mockup), a descriptive title, feature bullet points, and an action button ("Ver Demostración").
   - Success Stories / Case Studies Section:
     A grid or horizontal slider of fictional success stories displaying client metrics, logo placeholders, quotes, and impact statistics (e.g., "Automated 80% of HR screening", "Reduced response times by 95%").
   - About Inwit Section:
     Detailed company background explaining Inwit's mission to bridge human capability with specialized artificial intelligence agents. Include key figures/metrics (e.g., uptime, active agents, client satisfaction) and brand values.
   - Footer:
     Standard dark futuristic footer with links, copyright info for Inwit, social media icons, and a contact newsletter subscription input.

3. Design & Tech Specs:
   - Built in clean HTML5, CSS3, and JavaScript (vanilla or React).
   - Use CSS animations, CSS backdrop-filters for glassmorphism, flexbox/grid for layouts, and HTML5 Canvas for the interactive space background particle system.
